La contabilidad de tu empresa, ordenada

Sistema de Contabilidad

Registros, libros, conciliaciones y estados financieros en un sistema que se integra con facturación, nómina y bancos.

Ideal para: Contadores, despachos contables y áreas de finanzas.

Solución de Premium Soft, presentada por Gramanat como parte de su alianza comercial.

Según la información publicada por el fabricante, esta solución está disponible para El Salvador en versión Desktop. Consulta con Gramanat cuál se ajusta a tu negocio y en qué condiciones.

Solicita asesoría

Principales Características

  • Catálogo de cuentas adaptable.
  • Reportes contables bajo NIIF.
  • Contabilidad estructurada y confiable.
  • Varias empresas en un mismo sistema (solo versión Desktop).
  • Se integra con facturación, nómina y bancos.
  • Libros contables generados automáticamente.
  • Carga masiva de partidas desde Excel.
  • Usuarios con permisos definidos para cada función.

Requisitos del Sistema

Servidor

Base de Datos

MySQL 5.5.62 o superior

Memoria RAM

16GB RAM (para 1-10 computadoras)

Procesador

Intel i5/i7 12va generación 2.5GHz o superior

Almacenamiento

SSD 500GB

Sistema Operativo

Windows 10/11 (64-bit)

Componentes adicionales

Componentes y conexión

Impresora láser para reportes, software de hojas de cálculo compatible

Nota

Durante periodos fiscales críticos, se recomienda mayor capacidad de procesamiento.
