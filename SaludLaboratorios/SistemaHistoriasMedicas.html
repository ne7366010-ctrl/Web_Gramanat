Sistema de Historias Médicas

Registra y consulta historias médicas configurables por especialidad, con imágenes, convenios y estadísticas. Se integra con el Sistema para Clínicas y Hospitales.

Solución de Premium Soft, presentada por Gramanat como parte de su alianza comercial.

Según la información publicada por el fabricante, esta solución está disponible para El Salvador en versión Desktop. Consulta con Gramanat cuál se ajusta a tu negocio y en qué condiciones.

Solicita asesoría

Principales Características

  • Anamnesis y examen físico configurables por especialidad.
  • Formatos de historia adaptados a tu forma de trabajar.
  • Fotografía del paciente e imágenes complementarias, como radiografías y tomografías.
  • Vademécum propio con tus tratamientos más frecuentes.
  • Control de tus honorarios profesionales.
  • Convenios con empresas y aseguradoras.
  • Estadísticas médicas.
  • Reportes de gestión, como cuentas por pagar e ingresos y egresos bancarios.

Requisitos del Sistema

Servidor

Base de Datos

MySQL 5.5.62 o superior

Memoria RAM

8GB mínimo (16GB recomendado)

Procesador

Intel i3/i5/i7 2.4GHz 7ma gen o superior, o AMD Ryzen 3/5/7 2.4GHz 5ta gen o superior

Almacenamiento

SSD 500GB (o superior)

Sistema Operativo

Windows, Linux o macOS

Equipo de cada usuario

Sistema Operativo

Navegador moderno (Chrome, Firefox, Edge, Safari)

Memoria RAM

4GB mínimo (8GB recomendado)

Procesador

Procesador moderno de 64 bits

Almacenamiento

SSD 256GB o superior

Componentes adicionales

Componentes y conexión

Conexión estable a internet para funciones en la nube y actualizaciones

Nota

Los requisitos pueden variar según el volumen de datos y la cantidad de usuarios simultáneos. Para instalaciones grandes, consulta con un asesor.
